Install

UCompute is in development. There is no public release or download yet, and the source has not been published yet. These are the steps the project's own engineering uses, recorded here for when the source is available.{{claim:no-release}}{{claim:license}}

macOS on Apple M2

Tested on a MacBook Air with an Apple M2 and macOS 26.2. You need the Rust toolchain pinned in the repository's rust-toolchain.toml and free disk space for the Rust build, the engine (about 12 MB) and the models you download (491 MB for the recommended chat model).

cd ucompute          # a checkout of the source, once published
cargo build --release -p ucompute-cli
export PATH="$PWD/target/release:$PATH"

ucompute setup     # downloads and verifies the pinned llama.cpp engine (about 12 MB)
ucompute doctor    # checks the engine, disk and memory

ucompute setup downloads llama.cpp release b11609 and checks it against its pinned SHA-256 before use. Add --fixtures to also fetch the two tiny test models.

The desktop app

The desktop app is a Tauri 2 and React shell over the same local API. For development, run the daemon in one terminal and the app in another:

cargo run -p ucompute-cli -- serve --host 127.0.0.1 --port 8192   # terminal 1
cd apps/desktop && pnpm install && pnpm tauri dev               # terminal 2

pnpm dev instead opens the interface in a browser at http://localhost:1420. To build a Mac app and disk image:

cd apps/desktop && pnpm tauri build --bundles app,dmg

This produces UCompute.app and UCompute_0.1.0_aarch64.dmg. The build compiles the bundled daemon from the same checkout. The app starts that daemon with serve --host 127.0.0.1 --port 8192 --exit-with-parent, or reuses one that already answers on port 8192, and when you quit it stops the daemon it started.

Not notarizedMac builds are ad-hoc signed, not notarized. macOS blocks a downloaded copy the first time; allow it once in System Settings, Privacy & Security.

Windows 11 x64

Experimental

The daemon and the desktop app have been built and run natively on one Windows 11 laptop with an Intel Arc 140V GPU, using Visual Studio 2022 Build Tools, the Rust MSVC toolchain, Node 24 and pnpm. On Windows the engine uses Vulkan. In apps/desktop:

pnpm tauri build --bundles nsis

This produces an NSIS installer, UCompute_0.1.0_x64-setup.exe, that installs per user. It is unsigned. Several Windows issues are open; read the open issues before testing it.

Linux

Planned

Linux is planned, not supported. In tests, one Linux desktop (Ubuntu, processor only) ran a development build of the background program, compiled from source and started by hand. There is no Linux app, package or installer, and its first test run found open defects, one of them in crash cleanup. These docs will cover Linux once it is qualified; a headless daemon comes first.{{claim:platforms}}

Where your data lives

Models, the engine, device keys, settings and logs live in one data folder. Delete it to remove everything UCompute stored.

SystemDefault data folder
macOS~/Library/Application Support/UCompute
Windows%LOCALAPPDATA%\UCompute

Set UCOMPUTE_HOME to use another folder. See Configuration.
