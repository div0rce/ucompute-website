Documentation

Everything here describes the development code as of 23 October 2026, version 0.1.0. There is no public release yet, and commands and routes may still change before one.{{claim:no-release}}

About the nameUCompute was formerly called Common; trademark clearance is open and not claimed. Development builds still use the old name in places, so these docs do too where you have to type it: the command is common, the Mac app bundle is Common.app, and settings live in a folder called Common. Those change when the code is renamed, with a tested migration.

Conventions

  • Commands are for macOS or Linux shells unless marked. On Windows the binary is common.exe.
  • Status labels such as Experimental and Planned are defined on the roadmap.
  • Peer labels like 1a2b-3c4d-5e6f are examples. Use the ones your devices show.
