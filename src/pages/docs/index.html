Documentation

Everything here describes the software as committed at af3e37c, version 0.1.0. It is a development build: commands and routes may still change before a release.

About the nameUCompute is the project's public name in use; naming and trademark clearance are open and not claimed. Each UCompute name maps one-to-one to the Common name in the code: UCompute Run is Common Run, UCompute Mesh is Common Mesh. The software, its commands and its folders use the implementation name Common: the command is common, the app is Common.app, and settings live in a folder called Common. A rename will come with a tested migration.

Conventions

  • Commands are for macOS or Linux shells unless marked. On Windows the binary is common.exe.
  • Status labels such as Experimental and Planned are defined on the roadmap.
  • Peer labels like 1a2b-3c4d-5e6f are examples. Use the ones your devices show.
