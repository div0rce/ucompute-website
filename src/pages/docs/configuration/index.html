Configuration

The defaults are the safe ones: local only, networking off, bound to this computer. You only need this page to change that, or to move the data folder.

Options for common serve

OptionDefaultMeaning
--host127.0.0.1Address the HTTP API listens on. Must be an IP address.
--port8192HTTP API port
--api-keynoneRequired for any non-loopback host; then every route except /health needs Authorization: Bearer <key>
--max-concurrent4Generation slots
--networkoffTurn on peer networking. Saved to config.json, not just for this run.
--serve-peersoffLet paired devices run work here. Implies --network; also saved.
--listen-addr, --listen-port0.0.0.0, 8193The UDP peer endpoint
--no-mdnsmDNS on when networking is onDon't advertise or discover on the local network
--exit-with-parentoffUsed by the desktop app so the daemon ends with it

Starting with a non-loopback --host and no key is refused before anything is bound: refusing to listen on … without --api-key.

Settings in config.json

The daemon keeps its settings in config.json in the data folder, readable only by your user. The desktop app and the API change them for you.

FieldDefaultMeaning
privacylocal_onlylocal_only, trusted_group (after acknowledging the disclosure) or swarm_allowed (refused until its security gate)
network_enabledfalsePeer networking on or off
serve_peersfalseWhether paired devices may run work here
peer_quota.requests_per_minute120Per paired device
peer_quota.tokens_per_minute200000Per paired device
peer_quota.max_concurrent4Per paired device; peers never get the last engine slot

The data folder

Defaults: ~/Library/Application Support/Common on macOS, %LOCALAPPDATA%\Common on Windows, $XDG_DATA_HOME/common or ~/.local/share/common on Linux. Override it with COMMON_HOME.

PathContents
backends/llama.cpp/<release>/The verified engine
models/blobs/, models/manifests/Model files by SHA-256, and what each id points to
identity/This device's key pair and its paired peers
logs/audit.jsonlThe audit log: ids, counts, codes and timings, never prompts
runs/Manifests saved with --save-prompt
config.json, serve.jsonSettings, and the address of the running daemon

Environment variables

VariableEffect
COMMON_HOMEUse this data folder instead of the default
COMMON_MDNS=0Turn off mDNS discovery
COMMON_API_KEYKey the CLI's peer and group commands use to reach a key-protected daemon
RUST_LOGLog filter; overrides -v and -vv

Every command also accepts --json for machine-readable output and errors.
