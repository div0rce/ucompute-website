First run on a Mac

For invited testers, with UCompute {{alpha-version}}, the private-alpha build. This build is ad-hoc signed and not notarized.{{claim:installer}}

From the disk image to a first answer and a first API call, using only what the download contains. You don't need the source or Rust.

What you need

  • A Mac like the one this build was tested on: Apple M2, 8 GB, macOS 26.2. The build is for Apple Silicon only, and other Macs are not qualified.
  • About 600 MB of free disk: the app, the engine (about 12 MB) and the recommended model (491 MB).
  • The internet, for the engine and the model. After that, a first answer runs on your Mac alone.{{claim:run-local}}

1. Install it

  1. Download {{alpha-file}} from Release information.
  2. Check the file against the SHA-256 shown there: 
    shasum -a 256 ~/Downloads/{{alpha-file}}
  3. Open the disk image and drag UCompute to Applications.
  4. Open UCompute from Applications. macOS refuses the first time, because the build is not notarized.
  5. Open System Settings, then Privacy & Security. Scroll to the message about UCompute, choose Open Anyway and confirm with your password. Opening from the Finder's context menu no longer gets past this.

2. Get a first answer

The first launch downloads the inference engine and checks its hash. Then, in the app:

  1. On the first screen, under Get started, choose Download… next to the recommended model.
  2. Read the license and size, and confirm. A stopped download resumes next time.
  3. Choose Run. The model loads and the chat opens.
  4. Type a question. The answer is generated on this Mac, and the prompt stays here.{{claim:run-local}}

3. Call the local API

While the app is open, its background service answers on http://127.0.0.1:8192, on this computer only. On that address it needs no API key.{{claim:openai-clients}}

Check that it is up:

curl http://127.0.0.1:8192/health

Ask the model you just ran:

curl http://127.0.0.1:8192/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "qwen2.5-0.5b-instruct-q4_k_m", "messages": [{"role": "user", "content": "Say hello in five words."}]}'

The official OpenAI clients work with only the base URL changed. In Python, after pip install openai:

from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8192/v1", api_key="unused-on-loopback")
reply = client.chat.completions.create(
    model="qwen2.5-0.5b-instruct-q4_k_m",
    messages=[{"role": "user", "content": "Say hello in five words."}],
)
print(reply.choices[0].message.content)

In JavaScript, after npm install openai, in a file ending in .mjs:

import OpenAI from "openai";

const client = new OpenAI({ baseURL: "http://127.0.0.1:8192/v1", apiKey: "unused-on-loopback" });
const reply = await client.chat.completions.create({
  model: "qwen2.5-0.5b-instruct-q4_k_m",
  messages: [{ role: "user", content: "Say hello in five words." }],
});
console.log(reply.choices[0].message.content);

Every route and error code is in the API reference. Tool calling is not yet verified, and this is a tested subset, not complete OpenAI compatibility.{{claim:openai-clients}}

4. Use the command line

The ucompute command ships inside the app. To use the commands in these docs, point your shell at it:

alias ucompute=/Applications/UCompute.app/Contents/MacOS/ucompute
ucompute doctor

ucompute doctor changes nothing and downloads nothing. It prints the version, data folder, hardware, engine and models, and a warning for each problem. Add the alias line to ~/.zshrc to keep it.

If you get stuck

  • macOS won't open the app. Go back to step 5 of Install it. The message appears in Privacy & Security only after you have tried to open the app.
  • curl can't connect. The service runs while the app is open. Open the app and try again.
  • Anything else. Run ucompute doctor, then see Troubleshooting.

Remove it

Quit the app, then delete UCompute from Applications. Models, the engine, device keys, settings and logs stay in ~/Library/Application Support/UCompute until you delete that folder too. Nothing is removed for you.
