How it works

Pair two computers once. Then pick where each request runs; it runs whole on that computer.{{claim:mesh-pair-choose}}

  1. Pair

    Open pairing on one computer and type its six-digit code on the other.

  2. Allow

    On both computers, let the other one run prompts. Nothing runs remotely without it.

  3. Choose

    In chat, pick the computer that should run the request.

  4. Run

    The prompt crosses an encrypted connection and runs on that computer's own GPU or CPU.

  5. Get the answer

    It streams back and says which computer ran it.

    Shown on 19 October 2026 between a Windows laptop and a Mac, with development builds. No model was split.{{claim:demo-2026-10-19}}{{claim:planned}} The full record

OpenAI-compatible, on localhost.

Change the base URL and keep your client. Add target to pick the computer; every response says where it ran.

  • Official OpenAI clients

    Python and JavaScript, tested on an Apple M2 Mac. Tool calling is not verified yet.{{claim:openai-clients}}

  • Streaming and typed errors

    Server-sent events, one error shape, stable codes.

  • Local unless you say otherwise

    Listens on 127.0.0.1. A peer target needs your permission.{{claim:mesh-pair-choose}}

# Runs on this computer
curl http://127.0.0.1:8192/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model": "qwen2.5-0.5b-instruct-q4_k_m",
       "messages": [{"role": "user", "content": "Hello"}],
       "stream": true}'

# Runs the whole request on a paired device
curl http://127.0.0.1:8192/v1/completions \
  -H 'Content-Type: application/json' \
  -H 'X-UCompute-Target: peer:1a2b-3c4d-5e6f' \
  -d '{"model": "stories15M-q4_0", "prompt": "Once upon a time", "max_tokens": 32}'
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8192/v1", api_key="unused-on-loopback")

reply = client.chat.completions.create(
    model="qwen2.5-0.5b-instruct-q4_k_m",
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.choices[0].message.content)

# Run the whole request on a paired device instead
remote = client.chat.completions.create(
    model="qwen2.5-0.5b-instruct-q4_k_m",
    messages=[{"role": "user", "content": "Hello"}],
    extra_body={"target": "peer:1a2b-3c4d-5e6f"},
)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://127.0.0.1:8192/v1",
  apiKey: "not-needed-on-loopback",
});

const stream = await client.chat.completions.create({
  model: "qwen2.5-0.5b-instruct-q4_k_m",
  messages: [{ role: "user", content: "Hello" }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}

Trust boundaries and security reports

Local by default

The API listens on 127.0.0.1. Networking stays off until you turn it on.{{claim:run-local}}{{claim:local-only}}

Permission, not assumption

A pairing code, a group that allows it, and permission on both ends. Revoke any time.{{claim:transport}}{{claim:groups}}{{claim:revocation}}

Honest about the risk

The computer that runs your prompt can read it. Pair only computers you trust.{{claim:device-sees-prompt}}

Prompts stay out of logs

Audit logs record each off-device request without the prompt or the answer.{{claim:audit}}

Public compute waits

Running work for strangers stays off until an independent security review.{{claim:planned}}
