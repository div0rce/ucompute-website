Fifteen milestones, ordered by dependency.

The roadmap comes from the project specification. Progress is counted against its requirements ledger: 148 original requirements, each with acceptance criteria. A requirement counts as verified only when every criterion has been demonstrated, with evidence and a commit recorded. Counts below are from the ledger at commit af3e37c.

36 of 148 verified8 implemented, awaiting verification101 not started

What the labels mean

Verified
Demonstrated with recorded evidence: specific hardware, configuration and commit.
Development build
The code exists and runs in internal builds. It is not a release.
Experimental
Code and some real evidence exist, but the checks for calling it supported are incomplete.
Planned
Committed scope with no qualified implementation yet.
Hypothesis
An idea or research question to be tested, not a commitment.
Gated
Deliberately switched off until a named security review passes.

The order reflects dependencies, not importance. Every milestone is part of the full product's scope; a limited release can ship earlier ones and must say what it leaves out.

Release stages and their targets

Recent progress

  1. 19 October 2026

    Desktop to desktop. The Windows app was built natively on the laptop. The Mac and Windows apps paired through their screens and ran prompts in both directions. Evidence

  2. 19 October 2026

    Discovery on a phone hotspot. Each machine found the other within about a second, completing the discovery requirement.

  3. 18 October 2026

    The UCompute program. The specification was extended with the open computing infrastructure program, keeping every original requirement.

  4. 18 October 2026

    Windows and a second machine. The daemon ran on Windows 11 with Intel Arc through Vulkan, and the full trusted-device flow passed twice between two physical machines.

  5. 15 October 2026

    Trusted devices on one host. Device identity, default-deny policy, encrypted transport, discovery, pairing and remote execution: 13 requirements verified on a single machine, after five adversarial reviews.

  6. 14 October 2026

    Local inference. Real models on CPU and Metal, the CLI and the OpenAI-compatible API, with the official clients passing.
