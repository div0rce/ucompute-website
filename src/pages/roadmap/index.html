Fifteen milestones, ordered by dependency.

The roadmap comes from the project specification. Progress is counted against its requirements ledger: 148 original requirements, each with acceptance criteria. A requirement counts as verified only when every criterion has been demonstrated, with evidence and a commit recorded. Counts below are from the ledger as of 23 October 2026. The roadmap shows status and dependencies, not dates.{{claim:ledger}}

Five additional requirements extend the original 148 for the UCompute program: an independently implementable protocol, a versioned workload contract, evidence-scoped device participation, independent developer integration, and the compute-credit direction. All five are not started.{{claim:ledger}}{{claim:direction}}

What the labels mean

Verified
Demonstrated with recorded evidence for a specific configuration, build and commit (the specification's "verified reality"). A ledger row is VERIFIED only when every acceptance criterion has been shown.
Implemented, awaiting verification
The code exists; its acceptance criteria are not all demonstrated yet ("current implementation", ledger status IMPLEMENTED_UNVERIFIED).
Planned
Specified and committed, not built yet ("committed engineering scope"). Never a date.
Strategic hypothesis
A direction, experiment or business idea still to be decided. Nothing to use, buy or download.
Experimental
For platforms and products: code or bounded real evidence exists, but the support gate is incomplete. No platform is SUPPORTED yet.
