Run a model here, or on a device you trust.

UCompute is one foundation with four products. Run and Mesh exist today in development builds. Swarm and Cloud are planned, with no date, and stay switched off until they can be made safe and useful. UCompute was formerly called Common, and development builds still use the old name for some commands, files and folders.

What the status labels mean

UCompute Run

Your AI.
Your machine.

Experimental

Runs small open models on the computer in front of you, with no account and no UCompute service, through a desktop app, a command-line tool, or an OpenAI-compatible API on 127.0.0.1:8192. Downloading a model or the engine uses the internet. Demonstrated on an Apple M2 Mac (macOS 26.2) and a Windows 11 laptop with an Intel Arc 140V GPU; both platforms are experimental; other platforms are planned. The API was demonstrated on the Apple M2 Mac.{{claim:run-local}}{{claim:platforms}}{{claim:openai-clients}}

Works today

  • Real models on a pinned engineSmall open models in GGUF format through a pinned, hash-verified build of the llama.cpp engine, on CPU and on Apple Metal. The Windows build runs the same engine on Intel Arc through Vulkan.{{claim:engine}}
  • Size, license and fit firstA catalog of eight pinned models. Before you download one, you see its size, its license and whether it fits in memory, and every download is checked against a pinned SHA-256 hash. Demonstrated on an Apple M2 Mac (macOS 26.2); the platform is experimental.{{claim:catalog}}
  • Memory checked before loadingA memory check before loading. On 14 measured model and context combinations the estimate was within −4.6% to +8.9% of the engine's real footprint. The estimates are calibrated for Apple Silicon Macs.{{claim:memory-fit}}
  • Streaming and clear errorsStreaming, cancellation, and one error format with stable codes.{{claim:reliability}}
  • No silent substitutionsIf the GPU fails, the run falls back to the CPU and the reason is logged, and every error comes with a plain-language explanation.{{claim:gpu-fallback}}

Not yet

  • A public release or download for any platform. Mac development builds are ad-hoc signed and not notarized, Windows builds carry no code-signing certificate, and neither is released.{{claim:no-release}}{{claim:installer}}
  • Qualified Linux support, a second inference engine, and a verified tool-calling round trip.{{claim:not-yet-run}}
  • An install, from a fresh user account, that reaches a first answer through the interface alone, on macOS and on Windows.{{claim:installer}}

Run models: the guide

UCompute Mesh

Paired,
by your choice.

Experimental

Pair computers you control with a short code, decide which ones may run work for each other, and choose which one runs a request. Each request runs whole on one device; UCompute does not split a model across devices. Everything is off until you turn it on.{{claim:mesh-pair-choose}}

Works today

  • Pair with a short codePairing with a six-digit code, bound to the encrypted session. In single-machine protocol tests, a relay in the middle could not complete it, and more than five wrong attempts within a minute locked the window.{{claim:mesh-pair-choose}}{{claim:pairing-lockout}}
  • Encrypted and revocableTraffic between paired devices is encrypted and both ends are authenticated: QUIC with TLS 1.3 and device keys pinned at pairing. You can revoke a paired device at any time; in two-machine tests its connection closed less than a tenth of a second later. Tested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work.{{claim:transport}}{{claim:revocation}}{{claim:device-identity}}
  • Permission on both endsGroups decide who may run prompts, and both the sending and the serving device must agree. Per-device quotas for peers exist but are not yet verified at their default settings.{{claim:groups}}{{claim:local-only}}{{claim:quotas}}
  • Found nearby, or by addressDevices on the same home network or phone hotspot can find each other.{{claim:discovery}} Where a network blocks automatic discovery, as some campus Wi-Fi does, paired devices can still connect by address. An address alone is never trusted: the device must present the key it was paired with. Reconnecting by address was shown between one Mac and one Windows laptop on the same campus network, with development builds.{{claim:connect-at-address}}
  • Shown on two real machinesTested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work. See the evidence.{{claim:mesh-pair-choose}}{{claim:windows-pairing}}{{claim:demo-2026-10-19}}
  • Asks before opening the firewallOn Windows, UCompute asks before it lets your paired devices reach it through the firewall, and the rule it adds covers only its own program, on private networks. Shown on one Windows 11 laptop with a development build; Windows asks for administrator approval.{{claim:firewall-consent}}

Not yet

  • Pooling: splitting one model across devices so they compute parts of it together. It is planned and has not started.{{claim:planned}}
  • Connections across the internet, through NAT or relays, are not built yet. Mesh works on one local network only.{{claim:planned}}
  • The checks for a stable Mesh: default fairness when peers flood a device, Windows key-file protection, and many more independent pairs.{{claim:quotas}}{{claim:device-identity}}{{claim:release-stages}}

UCompute Swarm

Planned

Planned, with no date, and not built: opt-in contribution of spare capacity to people you don't know, with limits you would set before any work is admitted. It would stay disabled until isolation, metering, verification and abuse protections pass an independent security review.{{claim:planned}} Our direction: Run, private Mesh and self-hosting stay free, and a future network would use one credit balance, with sharing modes each owner chooses per device and free access for people they trust. Credits do not exist yet. Free does not mean unlimited. The direction{{claim:direction}}

UCompute Cloud

Planned

Planned, with no date: an optional managed service, such as operated deployments for teams. It does not exist today, no paid service is authorized, and it would be tested with real users before it became a product. Local and private use would never require an account or a subscription.{{claim:planned}}

One foundation underneath

Core, Protocol, Scheduler and SDK are parts of the system, not separate products.

Core

Experimental

The runtime: hardware detection, model planning, verified artifacts, the supervised inference engine and the local API.

Protocol

Experimental

The local HTTP API and an experimental peer protocol. There is one implementation, and no stability promise until an independent one interoperates.{{claim:protocol}}

Scheduler

Planned

Choosing where work should run from measured hardware, network and policy, and saying so when local is better. Not built: today you choose the target yourself.{{claim:planned}}

SDK

Planned

Versioned Python and TypeScript clients, not built yet. Until then, the official OpenAI clients work against the local API, demonstrated on an Apple M2 Mac.{{claim:planned}}{{claim:openai-clients}}
