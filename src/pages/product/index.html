Run a model here, or on a device you trust.

UCompute is one open foundation offered four ways. Run and Mesh exist today as development builds. Swarm and Cloud are planned, and stay switched off until they can be made safe and useful.

What the status labels mean

UCompute Run

Your AI.
Your machine.

Development build

Install, pick a model, press Run. No account and no cloud: the model runs on the computer in front of you, through a desktop app, a command-line tool, or an OpenAI-compatible API on 127.0.0.1:8192.

Works today

  • Real GGUF models through a pinned, hash-verified build of the llama.cpp engine, on CPU and on Apple Metal. The Windows build runs the same engine on Intel Arc through Vulkan.
  • A catalog of eight pinned models, each with its revision, SHA-256 and license. The license is shown before every download.
  • A memory check before loading. On 14 measured model and context combinations the estimate was within −4.6% to +8.9% of the engine's real footprint.
  • Streaming, cancellation, and one error format with stable codes.
  • No silent substitutions: if a model, quantization or GPU isn't available, you are told why instead of being given something else.

Not yet

  • A signed public installer for any platform. Mac builds are ad-hoc signed and Windows builds unsigned; neither is released.
  • Linux execution, a second inference engine, and a verified tool-calling round trip.
  • A fresh-account, interface-only first run on a clean Mac, which the desktop milestone still requires.

Run models: the guide

UCompute Mesh

Better
together.

Experimental

Pair computers you control, decide which ones may run work for each other, and send a whole request to the one with the right hardware. Everything is off until you turn it on.

Works today

  • Pairing with a six-digit code or a QR payload, bound to the encrypted session so a relay in the middle cannot complete it. More than five wrong attempts within a minute lock the window.
  • Each device holds its own Ed25519 key. Connections use QUIC with TLS 1.3 and pinned keys; a revoked key fails inside the handshake.
  • Groups decide who may run prompts, and both the sending and the serving device must agree. Peers get per-device quotas and can never take this device's last engine slot.
  • Discovery on the local network with signed mDNS adverts, or pairing by address when the network blocks multicast.
  • Recorded on two physical machines: a MacBook Air and a Windows laptop running each other's prompts. See the evidence.

Not yet

  • Pooling: splitting one model across devices so they compute parts of it together. This is milestone M4 and has not started.
  • Connections across the internet, through NAT or relays.
  • The promotion checks for a stable Mesh: default fairness when peers flood a device, Windows key-file protection, and many more independent pairs.

ModeWhat happensStatus
A. LocalThe request runs on this computer.Development build

Later, and only when it's safe

UCompute Swarm

Planned, off by default

Opt-in contribution of spare capacity to people you don't know, with limits you set before any work is admitted. It stays disabled in the code until isolation, metering, verification and abuse protections pass an independent security review. No payments, credits with cash value or tokens are part of the plan today.

UCompute Cloud

Hypothesis

Optional managed services built on the same open contracts, such as operated deployments for teams. It is a business hypothesis to be tested with real users, not a product. Local and private use will never require an account or a subscription.

One foundation underneath

Core, Protocol, Scheduler and SDK are parts of the system, not separate products.

Core

Exists

The runtime: hardware detection, model planning, verified artifacts, the supervised inference engine and the local API.

Protocol

Experimental

How devices identify, pair, authorize and exchange work. No stability promise until an independent implementation interoperates.

Scheduler

Planned, M5

Choosing where work should run from measured hardware, network and policy, and saying so when local is better.

SDK

Planned

Versioned Python and TypeScript clients. Until then, the official OpenAI clients work against the local API.

How the pieces fit

Platforms

No platform is declared supported yet. A Mac with Apple Silicon (tested on an M2 with macOS 26.2) and a Windows 11 laptop with Intel Arc graphics have recorded evidence and are experimental. Linux, other GPUs and mobile devices are planned and untested.
