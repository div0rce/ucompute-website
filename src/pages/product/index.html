Run a model here, or on a device you trust.

UCompute is one open foundation offered four ways. Run and Mesh exist today in development builds. Swarm and Cloud are planned, with no date, and stay switched off until they can be made safe and useful. Each UCompute name maps one-to-one to the Common name used in the code: UCompute Run is Common Run, and so on.

What the status labels mean

UCompute Run

Your AI.
Your machine.

Experimental

Install, pick a model, press Run. No account and no cloud: the model runs on the computer in front of you, through a desktop app, a command-line tool, or an OpenAI-compatible API on 127.0.0.1:8192.

Works today

  • Small open models in GGUF format through a pinned, hash-verified build of the llama.cpp engine, on CPU and on Apple Metal. The Windows build runs the same engine on Intel Arc through Vulkan.{{claim:engine}}
  • A catalog of eight pinned models. Before you download one, you see its size, its license and whether it fits in memory, and every download is checked against a pinned SHA-256 hash.{{claim:catalog}}
  • A memory check before loading. On 14 measured model and context combinations the estimate was within −4.6% to +8.9% of the engine's real footprint. The estimates are calibrated for Apple Silicon Macs.{{claim:memory-fit}}
  • Streaming, cancellation, and one error format with stable codes.{{claim:reliability}}
  • No silent substitutions: if the GPU fails, the run falls back to the CPU and the reason is logged, and every error comes with a plain-language explanation.{{claim:gpu-fallback}}

Not yet

  • A public release or download for any platform. Mac development builds are ad-hoc signed and not notarized, Windows builds carry no code-signing certificate, and neither is released.{{claim:no-release}}{{claim:installer}}
  • Linux execution, a second inference engine, and a verified tool-calling round trip.{{claim:not-yet-run}}
  • An install, from a fresh user account, that reaches a first answer through the interface alone, on macOS and on Windows.{{claim:installer}}

UCompute Mesh

Better
together.

Experimental

Pair computers you control with a short code, decide which ones may run work for each other, and choose which one runs a request. Each request runs whole on one device; UCompute does not split a model across devices. Everything is off until you turn it on.{{claim:mesh-pair-choose}}

Works today

  • Pairing with a six-digit code or a QR payload, bound to the encrypted session so a relay in the middle cannot complete it. More than five wrong attempts within a minute lock the window.{{claim:mesh-pair-choose}}{{claim:pairing-lockout}}
  • Traffic between paired devices is encrypted and both ends are authenticated: QUIC with TLS 1.3 and device keys pinned at pairing. You can revoke a paired device at any time; in two-machine tests its connection closed less than a tenth of a second later.{{claim:transport}}{{claim:revocation}}{{claim:device-identity}}
  • Groups decide who may run prompts, and both the sending and the serving device must agree. Per-device quotas for peers exist but are not yet verified at their default settings.{{claim:groups}}{{claim:local-only}}{{claim:quotas}}
  • Devices on the same home network or phone hotspot can find each other; otherwise you pair by address.{{if:acceptance}} A paired device can also be reached at a new address on a network that blocks discovery.{{claim:connect-at-address}}{{else}}{{/if}}{{claim:discovery}}
  • Tested between one Apple M2 Mac and one Windows 11 laptop with Intel Arc 140V on the same Wi-Fi network or phone hotspot, with development builds. {{if:acceptance}}Pairing works whichever of the two shows the code.{{claim:windows-pairing}}{{else}}The Mac showed the code; pairing started on Windows is not yet shown to work.{{/if}} Mac-to-Mac pairing is not yet shown to work. See the evidence.{{claim:mesh-pair-choose}}{{claim:demo-2026-10-19}}

Not yet

  • Pooling: splitting one model across devices so they compute parts of it together. It is planned and has not started.{{claim:planned}}
  • Connections across the internet, through NAT or relays. Mesh works on one local network only.{{claim:planned}}
  • The checks for a stable Mesh: default fairness when peers flood a device, Windows key-file protection, and many more independent pairs.{{claim:quotas}}{{claim:device-identity}}{{claim:release-stages}}

Later, and only when it's safe

UCompute Swarm

Planned

Disabled, with no date. Opt-in contribution of spare capacity to people you don't know, with limits you set before any work is admitted. It stays disabled in the code until isolation, metering, verification and abuse protections pass an independent security review. {{claim:planned}} Our direction: Run, private Mesh and self-hosting stay free, and a future network would use one credit balance, with sharing modes each owner chooses per device and free access for people they trust. Credits do not exist yet. Free does not mean unlimited. The direction{{claim:direction}}

UCompute Cloud

Strategic hypothesis

Optional managed services built on the same open contracts, such as operated deployments for teams. No date, and no paid service is authorized; it is a business hypothesis to be tested with real users, not a product. Local and private use will never require an account or a subscription.

One foundation underneath

Core, Protocol, Scheduler and SDK are parts of the system, not separate products.

Core

Experimental

The runtime: hardware detection, model planning, verified artifacts, the supervised inference engine and the local API.

Protocol

Experimental

The local HTTP API and an experimental peer protocol. There is one implementation, and no stability promise until an independent one interoperates.{{claim:protocol}}

Scheduler

Planned

Choosing where work should run from measured hardware, network and policy, and saying so when local is better. Not built: today you choose the target yourself.{{claim:planned}}

SDK

Planned

Versioned Python and TypeScript clients, not built yet. Until then, the official OpenAI clients work against the local API.{{claim:planned}}{{claim:openai-clients}}

Platforms
