Questions, answered plainly.

What UCompute does today, what it doesn't, and where each answer comes from. Every answer here follows the engineering capability snapshot of 23 October 2026.

Getting it

Can I download UCompute?

No. UCompute is in development. There is no public release or download yet.{{claim:no-release}} The release status page shows what exists for each platform and what has to happen before an installer appears.

What does it do today?

UCompute Run runs small open models on your own computer, with no account and no UCompute service. By default, your requests stay on your device. Demonstrated on an Apple M2 Mac (macOS 26.2) and a Windows 11 laptop with an Intel Arc 140V GPU; both platforms are experimental; other platforms are planned.{{claim:run-local}}

UCompute Mesh lets you pair your own devices with a short code and choose which one runs a request. Each request runs whole on one device; UCompute does not split a model across devices. Tested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work.{{claim:mesh-pair-choose}}

Which computers does it work on?

No platform is declared supported yet. macOS 26.2 on Apple M2 and Windows 11 on an Intel Core Ultra 7 258V with Arc 140V are experimental; Linux, other GPUs and mobile are planned.{{claim:platforms}}

Do I need an account?

No account is needed to use UCompute on your own computer, and there is no UCompute service to sign in to. Demonstrated on an Apple M2 Mac (macOS 26.2) and a Windows 11 laptop with an Intel Arc 140V GPU; both platforms are experimental; other platforms are planned.{{claim:run-local}}

Your prompts and your devices

Does my prompt leave my computer?

Your prompts and responses stay on your device unless you pair another device and choose to run a request there. Local-only mode refuses every off-device request. Downloading a model or the engine uses the internet.{{claim:local-only}}

The device that runs your request processes your prompt. Pair only devices you control or trust.{{claim:device-sees-prompt}}

How is traffic between my devices protected?

Traffic between paired devices is encrypted and both ends are authenticated: QUIC with TLS 1.3 and device keys pinned at pairing. Your device will not send work to a device you have not paired. Tested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work.{{claim:transport}}

A device you have not paired cannot send you work. Tested with several instances on one computer, not yet between two machines.{{claim:unpaired-inbound}}

What if I stop trusting a device?

You can revoke a paired device at any time. In our two-machine tests, its connection closed less than a tenth of a second after the revoke (0.012 s, 0.061 s and 0.053 s in three runs), and its next request was refused.{{claim:revocation}} Audit logs record each off-device request without the prompt or the response.{{claim:audit}} Tested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work.

Can it run one large model across several computers?

Not today. Each request runs whole on one device.{{claim:mesh-pair-choose}} Planned, with no date: running one model across several devices, an opt-in open network (UCompute Swarm), compute credits and an optional managed service (UCompute Cloud). None of these exists today.{{claim:planned}}

For developers

Does it work with my OpenAI code?

UCompute's local API works with the official OpenAI Python and JavaScript client libraries; only the base URL changes. Demonstrated on an Apple M2 Mac (macOS 26.2); the platform is experimental. Chat and completions with streaming; tool calling is not yet verified.{{claim:openai-clients}} The developer guide has the quickstart, and the API reference lists every route and field.

Can my app choose which device runs a request?

Yes, explicitly: the target field runs a request here or on a named paired device, and every response says where it ran. Nothing picks a device for you. Tested between one Apple M2 Mac and one Windows 11 laptop (Intel Arc 140V) on the same Wi-Fi network or phone hotspot, with development builds; pairing has been shown starting from either of the two. Pairing between two Macs is not yet shown to work.{{claim:mesh-pair-choose}} See choosing where it runs.

Cost and the project

What will it cost?

Nothing is for sale today. Our direction: "Free to use your own compute. Free to share when you choose. Earn when you contribute. Pay when you need more." Credits do not exist yet. Free does not mean unlimited.{{claim:direction}} The vision page explains the direction and what would have to be true first.

Where is the source code?

UCompute's code is licensed under Apache-2.0. The source has not been published yet.{{claim:license}} License and rules describes how contributions are planned to work once it is.

Was UCompute called Common?

Yes. UCompute was formerly called Common, and trademark clearance for the new name is open. Development builds still use the old name where you have to type it: the command is common, the Mac app is Common.app, and settings live in a folder called Common.

How can I help?

Read the ground rules, follow the roadmap, and keep any security problem private. Follow the project lists what you can do now and what waits for the source.
