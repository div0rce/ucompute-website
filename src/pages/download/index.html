Release status

UCompute is in development. There is no public release or download yet. Here is exactly what exists for each platform, and what has to happen before an installer appears on this page.{{claim:no-release}}

Current version 0.1.0, development builds only. No binary is offered for download.

Release information

{{releases}}

Before any supported release, the project's rules require it to record:

  • supported platforms and the pinned engine for each;
  • artifact hashes and the exact source commit;
  • dependency and model license notices;
  • the compatibility and deprecation policy;
  • known issues, and upgrade and rollback instructions.

Installers must also be signed by a publicly trusted identity: an Apple Developer ID with notarization on macOS, and a code-signing certificate on Windows. Neither exists yet. Installation, data retention, crash cleanup and rejection of a tampered update are rehearsed on the exact files before they ship.

Using UCompute on your own computer needs no account. Demonstrated on an Apple M2 Mac (macOS 26.2) and a Windows 11 laptop with an Intel Arc 140V GPU; both platforms are experimental; other platforms are planned.{{claim:run-local}}{{claim:platforms}}

The path to a release

Each stage has measured targets in the specification. These are targets, not results, and a failed security or update check blocks a stage even if everything else passes. No stage has started.{{claim:release-stages}}

  1. 1

    Private alpha

    At least five consenting testers; four of five reach a first answer from a clean account, through the interface only, within 15 minutes; 20 quit, crash and restart cycles with nothing left running.

    Not started
  2. 2

    External developer alpha

    Independent developers integrate without help; live Python and TypeScript tests on every advertised platform; a tested security contact.

    Planned
  3. 3

    Public developer beta

    Twenty or more independent testers, at least 90% install success per operating system, signed installers, and update, tamper and rollback tests.

    Planned
  4. 4

    Stable Run, then stable Mesh

    Thirty days of beta, at least 99% successful local requests per supported combination, and for Mesh at least ten independent device pairs.

    Planned
